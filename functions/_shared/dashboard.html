Anonymous daily aggregates only — no names, addresses, room codes, chat or cards are collected. Days are UTC. “Left early” means every human had left and the bots finished the game; “abandoned” means the room expired or the server stopped mid-game. New players are counted per server process with a daily in-memory key, so a server restart can count someone twice.
